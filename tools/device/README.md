# 장치 — 리추얼 기록을 넣으면 숫자와 문단 후보를 다시 만듭니다

## 이게 뭔가요
새 리추얼 기록 파일을 넣으면, 그 안에서
1. 숫자 칸(기록 일수, 기간, 강점 행동 실천 횟수 — 전부 출처가 붙어 있음)
2. 능력별(자기동기력·자기조절력·대인관계력) 문단 후보

를 다시 계산해서 `output/` 폴더에 저장하는 스크립트입니다. 외부 네트워크나 AI 서비스를 호출하지 않고, 순수 텍스트 규칙(키워드 매칭)만으로 동작합니다. 그래서 **같은 입력 파일을 넣으면 항상 같은 결과**가 나옵니다.

## 돌리는 방법 (3단계)

1. 파이썬 3이 설치된 컴퓨터에서 이 폴더(`tools/device/`)로 이동합니다.
   ```
   cd tools/device
   ```
2. 리추얼 기록 텍스트 파일을 넣고 실행합니다.
   ```
   python3 generate.py sample_input/ritual-history-sample.txt output
   ```
3. `output/stats.json`(숫자 칸)과 `output/paragraph_candidates.md`(능력별 문단 후보)가 새로 만들어집니다. 터미널에 출력되는 `입력 sha256(12)` 값이, 같은 입력 파일을 다시 돌렸을 때와 같은지 비교하면 재현성을 확인할 수 있습니다.

## 통과/실패 기준
- 통과: `output/stats.json`과 `output/paragraph_candidates.md`가 새로 생성되고, 같은 입력 파일로 두 번 돌렸을 때 두 결과 폴더가 완전히 같음(`diff` 결과 없음).
- 안 될 때: 파이썬 버전이 3 미만이거나, 입력 파일이 `## YYYY-MM-DD` 형식의 날짜 헤더를 포함하지 않으면 빈 결과가 나옵니다. 원본 리추얼 기록 다운로드 형식 그대로 넣어주세요.

## 주의
- `output/paragraph_candidates.md`에 뽑힌 문장은 **후보**일 뿐입니다. 사이트나 문서에 쓰기 전에 사람이 다시 읽고 고르고 다듬어야 합니다.
- 이 장치는 파일 안의 문장을 그대로 옮길 뿐, 다른 사람의 실명을 지우지 않습니다. 원본 리추얼 기록 자체가 이름 칸 가림 처리된 파일인지 먼저 확인하세요.
